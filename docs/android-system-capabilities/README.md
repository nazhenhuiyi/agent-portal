# Android 系统能力学习手册

[全部文档](../README.md)

一个 App 除了打开自己的页面，还能在桌面放一张卡片、提供动态背景、在锁屏提醒用户，甚至成为整个主屏幕。本手册研究这些**由操作系统提供入口、按系统规则运行的能力**。

用一个日程 App 贯穿前五章：桌面显示“14:00 项目会议”，背景随一天中的时间变化；会议改到 15:00 后，手机更新卡片并提醒用户。第六章再用音乐、打车等例子辨认不同的锁屏卡片。

## 先建立关系，再读接口

**主屏幕和锁屏是显示位置；小组件、通知等是提供内容的方式；推送解决远端消息如何到达。** Launcher 则是组织主屏幕的程序。把位置、能力和消息传递分开后，很多相似的外观就不容易混淆。

## 这套资料目前覆盖到哪里

我们采用原生 Android 的视角学习，Kotlin、Android Framework、Jetpack 都属于这一范围。苹果能力仅在需要辨认概念时作简短对照。

本手册与推送手册保存在并列目录中。当前完成的是机制学习和官方资料调研，尚未实现 App，也没有实测手机兼容性、耗电或更新延迟。平台 API 有这个能力，不代表某台手机开放了相同入口；厂商例子的适用范围见引用资料。

整理与本轮审阅日期：**2026-09-08**。教学例子不代表已经确定的产品方案。
